# Контрольные вопросы

1. Какие типы данных поддерживаает SQLite? Как в SQLite можно хранить логические значения и даты?
NULL - пустое значение
INTEGER - целые числа
REAL - числа с плавающей точкой
TEXT - текстовые строки
BLOB - бинарные данные
Хранение логических значений:
Логические значения хранятся как INTEGER:
0 -false
1 - true
Хранение дат:
Даты можно хранить несколькими способами:
TEXT - в формате ISO
INTEGER - Unix-время
REAL - юлианская дата

2. Для чего нужен класс SQLiteOpenHelper? Опишите назначение методов onCreate() и onUpgrade()
SQLiteOpenHelper - вспомогательный класс для управленния созданием и обновлением базы данных.
onCreate() - вызывается автоматически 1 раз, когда база данных создается впервые. Здесь создаются таблицы и начальные данные.
onUpgrade() - вызывается, когда версия базы данных увеличивается. Используется для изменения структуры: добавление/удаление столбцов, таблиц и т.д.

3. В чем разница между методами getWritableDatabase() и getReadableDatabase()?
getWritableDatabase() - 	Чтение + Запись, для INSERT, UPDATE, DELETE операций
getReadableDatabase() - 	Только чтение, для SELECT запросов

4. Что такое cursor? Как правильно перемещаться по его элементам и почему важно закрывать его после использования?
Cursor – это объект, который содержит результат запроса к БД и позволяет перемещаться по строкам.
Почему важно закрывать cursor:
Предотвращает утечку памяти
Освобождает ресурсы базы данных
Избегает ошибок IllegalStateException

5. Что такое ContentValues и для каких операций он применяется?
ContentValues – это контейнер, который хранит пары "ключ-значение" для вставки или обновления данных в БД.

Применяется для:

insert() – добавление новой записи

update() – обновление существующей записи

6. В чем отличие методов query() и rawQuery()?

query() - "Красивый" метод, аргументы передаются отдельными параметрами, защита от SQL-инъекций, удобство

rawQuery() - Принимает сырой SQL-запрос строкой, гибкость, сложные запросы

7. Как обработать ситуацию, когда таблица уже существует, но её структура была изменена (например, добавлено новое поле)?

В методе onUpgrade():

Увеличить DATABASE_VERSION
Удалить старую таблицу: db.execSQL("DROP TABLE IF EXISTS " + TABLE_NAME)
Создать новую: onCreate(db)
